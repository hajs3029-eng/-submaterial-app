발주 필요 품목

📦 타 부서 보유 현황

📦 전체 재고 입력

오늘 창고에서 확인한 현재 재고를 품목별로 한 번에 입력해 주세요.
이전 재고보다 줄면 사용, 늘면 입고로 자동으로 기록됩니다.

📋 재고 입력 기록

확인할 부서를 선택해 주세요. 선택하면 해당 부서에서 입력한 재고 기록을 표로 확인할 수 있습니다.

품목 관리

등록된 품목과 현재 재고를 확인할 수 있습니다.

🔐 관리자 모드

관리자 비밀번호를 입력해 주세요.

⚙️ 관리자 모드

전체 부서의 재고 상태를 한눈에 확인합니다. 품목을 누르면 부서별 상세 현황이 바로 표시됩니다.

🏷️ 부서별 품목 관리

먼저 대분류를 선택한 뒤, 해당 부서의 품목을 삭제하거나 새 품목을 추가할 수 있습니다.

🔑 관리자 비밀번호 변경

현재 비밀번호를 확인한 뒤 새 비밀번호로 변경할 수 있습니다.

📦 품목 상세 현황

📦 재고 수정 (관리자 권한)

수정할 날짜를 선택해 주세요. 과거 날짜의 재고도 입력·수정할 수 있습니다.

🏢 재고 수정 부서 선택

선택한 날짜에 재고를 수정할 부서를 선택해 주세요.

📅 월별 사용량 통계

재고확인 기록의 변동을 기준으로 부서별·품목별 사용량을 확인합니다. 당일 입력은 사용량 산정에서 제외됩니다.

📊 연간 사용량 통계

당해 연도는 올해의 사용량으로 표시하고, 1년·3년·5년 전 기간과 비교한 증감률을 확인합니다. 3년·5년 비교값은 각각 직전 3년·5년의 평균 사용량입니다.
